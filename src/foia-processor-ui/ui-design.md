# UI Design

Goal:
Modernize the existing React UI without changing business logic or API behavior.

Style:
- Clean, modern SaaS application
- Government/professional audience
- Dark midnight blue theme first
- Spacious layout, rounded cards, subtle shadows
- Avoid flashy gradients or overly playful visuals

Design system:
- Use existing React components where possible
- Prefer Tailwind utility classes
- Use consistent spacing: p-4, p-6, gap-4, gap-6
- Use semantic HTML and accessible labels
- Keep color usage restrained
- Use responsive layouts

Rules:
- Do not change data fetching logic
- Do not rename routes
- Do not alter API contracts
- Do not remove existing functionality
- Make changes incrementally
- Explain changed files before editing
